Slide 1 — Introduction to IoT Security

هذه الشريحة عنوان المحاضرة، وما فيها تعريفات للحفظ.

IoT Security يعني أمن إنترنت الأشياء، والمقصود دراسة الجوانب الأمنية للأجهزة الذكية المتصلة والخدمات اللي بتعتمد عليها.

مثلاً، لما نحكي عن كاميرا ذكية، إحنا مش بس بنهتم إذا الكاميرا نفسها آمنة؛ بنهتم كمان بالتطبيق اللي بتحكم فيها، والشبكة، والخدمات السحابية، والأشخاص اللي عندهم صلاحية الوصول إلها.

هاي الفكرة هي أساس المحاضرة كلها.

الفكرة الأساسية

تخيّل عندك كاميرا مراقبة ذكية بالبيت.

الكاميرا فيها Hardware وSoftware، وبتتصل بالشبكة، وبتتواصل مع خدمات خارجية، وبتتحكم فيها من تطبيق على الموبايل.

يعني النظام مش مجرد كاميرا معلّقة على الحيط.

خلينا نفهم مكوناته:

  • Hardware: الكاميرا نفسها، المعالج، والذاكرة.

  • Software: البرنامج اللي بشغّل الكاميرا.

  • Network: الشبكة اللي بتوصل الكاميرا بالخدمات الأخرى.

  • Cloud Service: الخدمة اللي ممكن تخزّن التسجيلات أو تدير الحساب.

  • Mobile Application: التطبيق اللي بتستخدمه لمشاهدة الفيديو والتحكم بالكاميرا.

وين ممكن تكون المشكلة الأمنية؟

افترض إن الكاميرا نفسها ما فيها أي مشكلة واضحة، لكن حساب المستخدم ضعيف أو الخدمة السحابية فيها خلل.

Case Study — Smart Camera

Scenario (English):

A smart security camera is functioning correctly, but its owner cannot access recordings because the remote cloud service is unavailable.

Question: Identify the affected ecosystem component and explain why the camera may be affected even though its hardware is functioning.

إظهار الإجابة النموذجية

Correct Answer (English):The affected component is the Cloud Service. The camera depends on remote services for certain functions, so a cloud failure may interrupt access to recordings even when the camera hardware is functioning.الشرح بالعربي:الكاميرا شغالة، لكن الخدمة اللي بتعتمد عليها للوصول للتسجيلات مش متاحة. إذن المشكلة في Dependency خارج الجهاز نفسه.Exam Keywords: Cloud Service, Remote Access, Dependency, Service Unavailability.

الرسم بيوضح مكونات النظام بشكل تسلسلي للتعلّم، لكن مش شرط كل جهاز يمر عبر Gateway أو يتبع نفس المسار.

شرح المكونات واحد واحد

1. Physical Device — الجهاز الفيزيائي

هو الجهاز الموجود فعليًا في البيئة.

يتكوّن من:

  • Sensors: حساسات بتجمع معلومات من البيئة.

  • Actuators: أجزاء بتنفّذ أفعال فيزيائية.

  • Processor: معالج بنفّذ العمليات والتعليمات.

مثال: في Smart Lock، ممكن يكون في حساس لحالة الباب وآلية قفل بتنفذ أوامر الفتح والإغلاق.

2. Device Software — برمجيات الجهاز

هي البرامج اللي بتحدد كيف الجهاز يبدأ التشغيل، وكيف يتصرف، وكيف يخزّن إعداداته ويتواصل.

Boot: عملية بدء تشغيل الجهاز.

Configuration: إعدادات الجهاز.

Application: البرنامج اللي بينفذ وظائف الجهاز.

3. Connectivity — الاتصال

هي الطرق اللي الجهاز بستخدمها للتواصل مع المكونات الأخرى، سواء محليًا أو عبر الإنترنت.

مهم: الاتصال مش محصور بالـWi-Fi.

4. Gateway / Edge — البوابة أو الطبقة الوسيطة

هي مكوّن ممكن يربط أجهزة محلية بشبكات أو خدمات أخرى.

ممكن يقوم بتجميع البيانات، أو تحويل طريقة الاتصال، أو المعالجة المحلية.

مثال: عدة حساسات داخل مبنى ترسل بياناتها إلى Gateway واحد، وهو بدوره يرسلها للخدمة البعيدة.

5. Cloud Service — الخدمة السحابية

هي الخدمات البعيدة اللي ممكن تخزّن بيانات الأجهزة، وتدير الحسابات، وتسجل الأجهزة، وترسل الأوامر.

مثال: خدمة تخزين تسجيلات كاميرا ذكية.

6. User Application — تطبيق المستخدم

هو واجهة التفاعل بين الإنسان والنظام، مثل تطبيق الهاتف أو صفحة الويب.

من خلاله ممكن المستخدم يشاهد المعلومات أو يرسل أوامر.
